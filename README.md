# زخرفة (Zakhrafa Handmade) — المشروع الكامل

المشروع ده متكون من جزئين لازم يشتغلوا مع بعض:

```
zakhrafa-full/
├── backend/     ← السيرفر: API + قاعدة البيانات + لوحة التحكم
└── frontend/    ← الموقع اللي بيشوفه الزبون (المتجر)
```

## 1) تشغيل الـ Backend (شغّله الأول)

```bash
cd backend
cp .env.example .env
npm install
npm run dev
```

- السيرفر هيشتغل على: `http://localhost:4000`
- لوحة التحكم (الأدمن): افتح `http://localhost:4000/admin.html`
  - الباسورد الافتراضي موجود في ملف `.env` بعد ما تعمل `cp .env.example .env` — غيّره لباسورد قوي بتاعك.

## 2) تشغيل الـ Frontend (في Terminal تاني، من غير ما تقفل الأول)

```bash
cd frontend
npm install
npm run dev
```

- الموقع هيفتح على: `http://localhost:5173`
- الموقع بيجيب المنتجات وبيبعت الطلبات لنفس الـ backend أوتوماتيك.

## 3) تفعيل الدفع الإلكتروني (Paymob)

1. افتح حساب تاجر على [Paymob](https://paymob.com) ببيانات نشاطك التجاري.
2. من لوحة تحكم Paymob هتلاقي: `API Key`, `Integration ID`, `Iframe ID`.
3. حطهم في ملف `backend/.env`:
   ```
   PAYMOB_API_KEY=...
   PAYMOB_INTEGRATION_ID=...
   PAYMOB_IFRAME_ID=...
   PAYMOB_HMAC_SECRET=...
   ```
4. أعد تشغيل السيرفر — الدفع هيتفعل أوتوماتيك، ومفيش حاجة تانية تتعدل في الكود.

قبل ما تحط بيانات Paymob الحقيقية، أي طلب هيتسجل عادي في النظام وهيظهرلك في لوحة التحكم، والزبون هيشوف رسالة إن التواصل هيتم يدويًا لحد ما الدفع يتفعل.

## 4) إدارة المنتجات والطلبات

من `admin.html`:
- **ضيف منتجات جديدة** (الاسم، الفئة، السعر، الكمية، الوصف)
- **احذف منتجات**
- **شوف كل الطلبات** اللي جاية من الزباين، بالاسم والتليفون والإجمالي

> ملحوظة: الصور دلوقتي أيقونات SVG بسيطة بدل صور حقيقية. لإضافة صور حقيقية للمنتجات محتاجين نضيف رفع صور (upload) — الخطوة دي جاهزة نعملها في أي وقت.

## 5) قبل ما تنشر الموقع فعليًا (Deployment)

- **قاعدة البيانات**: دلوقتي بتتخزن في ملفات JSON بسيطة (`backend/data/`) — كويسة للتجربة، بس لو الطلبات كترت ممكن ننقلها لقاعدة بيانات حقيقية زي PostgreSQL.
- **الاستضافة**: هتحتاج تستضيف الـ backend (مثلاً على Railway أو Render) والـ frontend (مثلاً على Vercel أو Netlify)، وتربط بينهم برابط حقيقي بدل `localhost`.
- **الدومين**: اشتري دومين واربطه بالـ frontend بعد النشر.

أي خطوة من دول لما تكون جاهز لها، قولّي وهنكملها مع بعض خطوة خطوة.
